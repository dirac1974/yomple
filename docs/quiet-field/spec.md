# Quiet Field 2 — "The Night Before" (synthesis spec)

Synthesis of `memory-science.md`, `game-design.md` and `voice-audio.md` in this folder. Built at `/field-next/` (yomple.com/field-next/) beside the untouched live `/field/`. Read all three memos; this spec decides where they disagree.

## Decisions

1. **Lanterns:** the memory scientist's **18 lanterns g1–g18 in three movements** (I. THEN g1–g2, II. NOW g3–g11, III. AHEAD g12–g18), verbatim Bliss text, titles and hinges exactly as in `memory-science.md` §2. Each lantern stores `from:"pX"`. Old `p` records are kept untouched for rollback.
2. **Migration:** new record = parent's state minus one level (never below "practicing"; never above what the parent had), due today. Seams start fresh. Done on first open per profile, idempotent (`fun.migratedV2 = true`).
3. **Concept:** the game designer's **"The Night Before"** — 18 Nov 1863, dusk, walking from the railway depot through the Diamond, up Baltimore Street, to the cemetery gate and the platform. The 18 lanterns are posts along that route = the memory palace stations (Movement I depot & Wills House; II Baltimore St → cemetery gate → graves → platform; III looking out from the platform). A growing crowd of silhouettes. Dusk for two weeks, then daylight only at the Dedication.
4. **Practice (one "Tonight" button runs a session ≤ 10–12 min):**
   - **Cold recall first** (memory: strongest evidence): session opens with a Night Walk of the lit lanterns due today.
   - **The Ladder** (replaces Echo/Fading Ink/Letter Trail as one cue-fading engine): rungs = full text → function words blanked → first letters of every word → first letters of content words only → title + picture. She *types the first letter* of each next word (letter-trail input) or *speaks it* (mic); the word inks in gold. Success climbs a rung; a peek drops one rung (never to zero). Karaoke "Hear it" uses the word timings.
   - **The Seams:** end of lantern N (last 3–4 words) → she gives the first 3–4 words of N+1 (typed first letters or spoken). 17 seams tracked as items.
   - **Night Walk:** whole path (or a movement) from title/picture only, with a **"Line!"** prompter button (next 2 words) — rehearsal, never failing.
   - **Scattered Pages** (order, recognition only, variety; never evidence).
   - **CUT:** Printer's Proof / any game that shows misquoted text (plants intrusions — memory memo).
   - New lanterns per day ≤ 3. Order: forward between movements, backward-cumulative within each (memory §3.9).
5. **Evidence (hard):** a lantern is *shining* after recall from title/picture with ≥ 90% words in order on **two different days with sleep between**; a seam likewise. Display never goes down. Mic only promotes: LCS-ordered fuzzy match with the mishearing table (voice memo §4); ≥ 0.75 credit; below → "Here's what I caught" + "Did you say it all?" trust her; never `markHit(false)`, never red, never resets a streak. Misses are soft gold ink; two misses on one item → "set by the window for tomorrow".
6. **Dedication (payoff):** unlocks at readiness (all shining + two full runs on different days ≤ 2 prompts). Scene, not a test: crowd, chorale, "Mr. Everett has spoken for two hours…", then she chooses *With my page* (first-letter cue sheet) or *From memory*; both complete it; hint taps allowed and never shown; optional MediaRecorder recording saved on-device only (IndexedDB), playback/keep/delete; certificate "Delivered by Sarah, <date>". Always repeatable.
7. **Collectibles:** Field Notes (one true primary-source card per lantern; silhouettes until found); Word Detective (8 × "here", 6 × "dedicate", 5 × "nation" — each answer is a memory hook). The Five Copies mystery is later.
8. **Voice:** new `voice.js` exposing `FieldVoice` (API in voice memo §5) with compatibility shims. Plays **per-lantern MP3 files** (no seeking — the cuts can't be off) from `audio/<voice>/<gid>.mp3` + `timing.json` (word times relative to the full recording; per-lantern clip offset = `lanterns[g].s`). Current voice: **Britton Rea**, re-cut tonight from word-level forced alignment (Vosk) at the quietest point of each join and verified clip by clip. When the ElevenLabs key arrives, a designed "imagined Lincoln" voice drops in as `audio/lincoln/` with the same files; a voice picker in settings ("Imagined Lincoln (computer voice)" / "Britton Rea (human reading)"). Playback via WebAudio (AudioContext unlocked in the first tap, `navigator.audioSession.type='playback'` where present), slow mode 0.8× with preservesPitch (or generated slow takes later). Atmosphere (WebAudio reverb, wind, distant crowd, optional "pretend old recording" crackle) **only** in the whole-address listen and the Dedication, toggle in settings; learning audio stays dry.
9. **Speech recognition:** feature-detected; fresh recognizer per attempt; 8 s watchdog; play audio via WebAudio (not `<audio>`) to avoid the iOS hang; hidden when unavailable (typed first letters remain).
10. **Offline:** `field-next/sw.js` scoped to `/field-next/`: precache shell + timing + all clips for the selected voice (~2.6 MB); `navigator.storage.persist()`.
11. **Look:** Quiet Field dusk palette + memo tokens (`--ember`, `--brick`, `--shadow`, `--frost`, `--noon`); one inline SVG scene in three parallax layers (ridge / town with lit windows, gatehouse, Wills House / path with posts); flickering lanterns; crowd silhouettes from `<symbol>`s; speech set in a serif (Iowan Old Style → Georgia) as ink on paper. No emoji as UI (Yomple badge excepted). Reduced motion respected. Not childish: a museum at closing time.
12. **Keep:** Yomple household/profile/sync/handoff code (`sync.js`, `arrive.js`, `yomple-stay.js`) — copied into `/field-next/` unchanged except paths; same `field_players` table and the same localStorage key so progress is shared with the live version (new data lives under new keys inside the same profile record: `fun.v2`, `progress.gettysburg.g1…`). The Preamble path stays available using the old flow until it gets its own cuts.

## Module contract (two builders)

- **Builder A (data, memory engine, voice, offline):** `field-next/lanterns.js` (TOPICS/GETTYSBURG2 with g1–g18, movements, hinges, field notes, pictures ids), `field-next/memory.js` (state, ladder rung per lantern, seams, due/scheduling by calendar day, evidence rules, migration, session builder `buildTonight(profile)` → list of steps), `field-next/voice.js` (`FieldVoice` + shims), `field-next/sw.js`, unit tests in `field-next/tests/` (node).
- **Builder B (scene, screens, games, ceremony):** `field-next/index.html`, `styles.css`, `app.js`, `scene.js` (SVG scene/crowd/lanterns), `games.js` (Ladder, Seams, Night Walk, Scattered Pages), `ceremony.js`. Uses only A's public APIs.
- Shared contract (A implements, B consumes):
  - `QF.lanterns(topic)` → `[{id,n,movement,title,text,words:[...],hinge,from,pic,note}]`; `QF.movements(topic)`.
  - `QF.state(profile, topic)`; `QF.rung(id)`; `QF.record(id, {kind:'ladder'|'seam'|'walk'|'mic', ok, rung, prompts, ratio})` → `{state, rung, lit, shining, tomorrow}`; `QF.seams()`; `QF.buildTonight()` → `[{kind:'walk'|'ladder'|'seam'|'pages', ids:[...]}]`; `QF.readiness()` → `{ready, missing}`; `QF.markDelivered({mode, date})`.
  - `FieldVoice.unlock()`, `.load(topic)`, `.play({lantern|from,to|full, speed, atmosphere}) → playback{on('word'|'end'), stop()}`, `.words(topic)`, `.canListen()`, `.listen(lanternId,{timeoutMs})`, `.setVoice(id)`, `.setAtmosphere(on)`.

## Amendments after the adversarial review (these win over the decisions above)

**Data safety (done server-side 2026-10-18):** rows backed up to `backup.field_players_20261018`; `yomple_player_upsert` now merges top-level keys for `field_players`. Cloud check showed every profile's Gettysburg records at state 0–3 on p1 only (Sarah: all 0), so migration is low-stakes.
- v2 data lives in **top-level** `progress.qf2` and `fun.qf2` (never inside `progress.gettysburg`). Old keys are read, never written by field-next, except sync must send them back unchanged.
- field-next uses its **own localStorage key `quiet-field-v2`**: on first boot deep-copies `quiet-field-v1` if v2 is absent; never writes v1. Reload store on `pageshow`/`visibilitychange`.
- `arrive.js` copy gets one fix: never `cloudSaveActive()` from the catch/failed-lookup path; create a fresh profile only on a confirmed not-found. Check `{ok:false}` results from upsert (log, retry later); never upload a `qf2` with fewer lantern records than last loaded.
- Save once per lantern result, no attempt logs.
- **Migration** fills only missing `g` records: split lanterns (g1/g2 from p1 etc.) get parent state − 1 (min 0), unsplit ones copy the parent; display level = parent's; due today. Re-run after any cloud row is applied.
- **Dates** by local calendar day (`getFullYear/getMonth/getDate`), never `toISOString()`.
- Integration: classic scripts, load order `yomple-stay.js → lanterns.js → memory.js → voice.js → app.js (+scene/games) → sync.js → arrive.js`; keep the globals and DOM ids sync.js/arrive.js need (`store, saveStore, getActiveProfile, slugName, YOMPLE_TABLE, YOMPLE_STORE, toast, showScreen, showHome, showProfiles, seedIntroduced`; ids `find-user, screen-recover, main-nav, family-code-value, parent-email, recover-*, otp-row, restore-code`). All `QF.*` calls read the active profile.

**Learning fixes:** the session opens with **cold recall = top-rung Ladder** (title + hinge only, typed first letters) on due lanterns — that is evidence; the Night Walk stays rehearsal. "≥ 90%" = words entered without gold ink, peek or Line!. Day 1 (nothing lit): whole-address karaoke listen, then g2, then g1 (backward within Movement I). Typed first letters only tonight (no mic in Ladder/Seams).

**iPad input:** one persistent hidden input (`autocapitalize=off autocorrect=off autocomplete=off spellcheck=false`), read on `input`, never re-rendered; layout above the keyboard via `visualViewport`. A tap anywhere on the page refocuses it. Also accept hardware keys.

**Audio:** 15 ms gain ramps in `play()`; unlock with `resume()` + silent buffer in `touchend`/`click`; handle `interrupted`; mute-switch hint when no `navigator.audioSession`. Known rough joins g3|g4, g6|g7, g12 end — listen on iPad; ElevenLabs takes replace them later.

**Cut tonight:** Dedication/recording/certificate (readiness is ~2 weeks away; show the platform at the path's end as "The Dedication waits here"), atmosphere, voice picker, slow mode, mic, Scattered Pages, Word Detective, Field Notes beyond 3 checked facts, parallax, per-lantern pictures (use serif station cards + hinge sentence), Preamble port (the Preamble card links to `/field/?u=…&f=…`). Service worker last, network-first for HTML/JS, never intercept Supabase; navigations matched with `ignoreSearch`.

**Minimum lovable session ("Tonight")**: cold recall (top rung) → ≤ 3 new lanterns on the Ladder with karaoke Hear it, gold ink, two-miss "by the window" → Seams for new joins → short Night Walk with Line! → close on a newly lit post, flame/bell, and a one-line teaser for tomorrow. The juice is required: pentatonic tick per correct letter, ink-in, flame jump, ignition + bell on a lit post.
