Privacy

Yomple games are made for families. We keep as little as we can.

What stays on your device

Player name, avatar, theme, and game progress are saved in the browser on that device so the garden is still there next time.

What optional family sync stores

If a grown-up creates a family code, progress can be saved in our database so another phone or tablet can pull the same players. That store is only the game data needed to continue play. We do not sell it. We do not use it for ads.

Optional grown-up recovery email

A parent may save an email with the family code so the garden can be found if the code is lost. Kids are never asked for mail. That email is used only to look up the family code.

What we do not collect

  • No email from kids inside the games
  • No location
  • No advertising trackers
  • No sale of personal information
